# Tech Challenge 04 - Voice of Customer Intelligence com RAG

Este repositório contém a solução do Tech Challenge 04, focada em construir um sistema de RAG (Retrieval-Augmented Generation) para explorar avaliações de clientes do e-commerce brasileiro.

## Estrutura do Projeto

* `data/`: Armazena os dados brutos (Brazilian E-Commerce Public Dataset by Olist).
* `notebooks/`: Notebooks de exploração de dados, limpeza, tratamento e criação dos embeddings e base de conhecimento.
* `src/`: Código-fonte para a execução do pipeline RAG.
